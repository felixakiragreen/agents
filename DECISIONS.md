# Decisions

The decision register: proposals awaiting ⬡'s blessing, and blessed rulings not yet
distilled into their canon homes. Law lives where it binds — the doctrine, the
standard, the charters, the mantles README, MAP, the global file; this file is the
queue and the staging ground, never the archive: git is. Ids are monotonic, never
reused; a gap in the numbering is a killed entry. Before minting: does this serve
the issue an ancestor was addressing, better? — amend the ancestor's home, mint
nothing; only a new issue mints (the ancestry test — grand-architect.md, DOCTRINE
§8). The Coding Directives are D-entry-governed: every value change rides this
register.

- **D82** (2026-09-01, Felix · ⬡✓ 2026-09-01): **The go-mark.** Felix's yes carries two

  `⬡ go ‹date›` means proceed without his eyes — authorization on credit, the review
