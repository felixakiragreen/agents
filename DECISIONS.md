distilled into their canon homes. Law lives where it binds — the doctrine, the
standard, the charters, the mantles README, MAP, the global file; this file is the

nothing; only a new issue mints (the ancestry test — grand-architect.md, DOCTRINE
§8). The Coding Directives are D-entry-governed: every value change rides this
register.
