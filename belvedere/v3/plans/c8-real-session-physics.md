## Mission

Layer 1 (cornerstone §6): **the same engine, real `claude -p` subjects**, small
topologies, ×3 accounts. Measure what the fake cannot — real latency, real
cost, real permission physics, kill/survive truth on real bytes — and table the
nine capabilities *through the engine* for campaign bar 4, plus the cost inputs
bar 5's extrapolation needs. The bet this dig can wound: the engine's sensing
on real events.

## Questions

1. **Sensing truth.** The engine's parse rules on real streams — last `result`
   is the turn, `permission_denials[]`, `init.permissionMode` read-back, the
   `--json-schema` report — hold ×3 accounts? Evidence per run: run log +
   stream files + transcript pointers.
2. **Bar 4's matrix.** The nine capabilities (cornerstone §4) exercised
   *through the engine*, ×3 accounts at sonnet·low, tabled like C4's scorecard
   with C4 as the control column. The census's ten events accounted for
   headless: 8 expected present, `Notification`/`PreCompact` structurally
   absent (C4 F4) — confirm or correct under the engine.
3. **The numbers.** Spawn latency, turn latency, cost/turn distributions —
   G4 bar-5 inputs, conditions attached.
4. **Kill + survive on real bytes.** (a) Subject SIGKILLed mid-turn: torn
   stream → the cursor answers for the fired turn (C11 live, on real bytes).
   (b) Engine SIGKILLed mid-flow: the orphan finishes on disk, the restart
   adopts or re-derives, converges, **zero double-ignitions** — exactly-once
   is now a spend property. Each cut class ≥3 runs.
5. **needs-⬡ live.** A permission denial pauses loud with its cause; a question
   pauses `needs_input` via the report; a posture mismatch (haiku + `auto`)
   refuses at ignite. One cheap probe each.
6. **The summon round trip.** An engine-born step summoned to a real TUI, one
   hand turn, resumed headless *by the engine* — one session id throughout, and
   the cursor survives the hand turn (C11's named hazard, field-tested).
7. **Real flows.** ≥3 topologies (3–6 steps; one carrying a gate or card; one
   with parallel width ≥2) run to terminal ×3 accounts, `invariants` green per
   run — a red files with its run dir, log, and transcript pointers (real runs
   are not seed-reproducible; pointers are the repro).

## The grant

An engine defect that blocks ≥2 questions may be fixed **in its own commit**,
full barrage green as regression, filed as a finding for ratification at
review (the door's granted-fix shape; C7 F4's ratified precedent). Anything
larger: BLOCKED, escalate.

## Kill criteria

- **K1 — sensing falsified:** a C4-measured parse rule contradicted on ≥3 runs
  across ≥2 accounts (control: the same drill green elsewhere the same day) →
  stop that line, file with captures; the engine fix is a new charge, never
  in-dig beyond the grant above.
- **K2 — the budget:** either ceiling → stop the whole dig, ⬡-fork.
- ≥3 same-class invariant reds across distinct drills → stop that drill class,
  land what stands.

## Escalation points

- Any auth, login, or trust dialog on an account — only Felix's hands.
- Any settings or hook change wanted in a live config dir — never; file it.
- Nothing third-party is named here, so nothing is authorized (D54).
