so the register walks this tree only when `GLASS_CITY` names it — which is what
`bun camera/cli.ts run --fixture` does. Every row below exists so that one card state
renders **on demand** instead of when reality happens to produce one.

building is ever wired to a Dispatch button. Beta is the building that fires.
