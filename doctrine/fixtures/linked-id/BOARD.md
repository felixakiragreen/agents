# A board that LINKS its id (snappy's whole board — 049-F7)

The address IS the ID cell, and here the cell is a link. The id inside it moves with the path
beside it, or the board keeps the old spelling while its own link leads to the new one — and the
round-trip check, which looks a row up by its respelled id, reads the row as vanished.
